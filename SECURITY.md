# Security

This is a process-and-paper repo. No code to exploit, two things worth reporting fast anyway.

**Guidance that would weaken someone's vendor program.** Companies run real third-party risk off these pages. If a question is missing its teeth, a clause would backfire in negotiation, or a play in here would leave an adopter more exposed, open an issue. That bug propagates into other people's registers, and it jumps the queue.

**Anything that looks client-identifiable.** Nothing here should come from a real engagement. If you spot something that looks like it did, do not open a public issue. Use GitHub's private vulnerability report on this repo, or the contact on [my profile](https://github.com/HarrisonWard), and it gets handled quietly and quickly.

No bounty program. The reward is one more company that knows exactly what it is trusting its vendors with.
